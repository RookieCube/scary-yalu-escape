# SCARY_YALU_ESCAPE

第一人称恐怖迷宫（Godot 4.7.2 / Forward+ / Jolt Physics）。

你是 **RookieCube**（名称可在主菜单修改，会自动保存）。
你被困在一座不断变化的黑暗迷宫里，
追杀你的方块恶鬼名叫 **Minecraft_Yalu** —— 找到绿色符文之门，逃出去。

## 运行

- 用 Godot 4.7+ 打开本目录（或直接 godot --path . 运行）
- 建议戴耳机游玩：Yalu 的脚步声与低语是唯一的预警

## 操作

- WASD / 方向键：移动
- 鼠标：视角
- Shift：冲刺（耗体力、发出噪音）
- Ctrl：蹲下（安静潜行）
- F：手电筒开关（耗电，亮光会暴露你）
- Q：使用道具（/afk、网络炸！！，拾取后自动入栏）
- E：阅读日记残页
- M：小地图 ESP 开关（全图显示迷宫结构、出口、电池、钥匙金点与 Yalu 红点位置）
- ESC：暂停（菜单里也有同样两个开关按钮）

> 两个开关的状态会自动保存，下次启动沿用。

## 规则

- 迷宫每局随机生成；开局墙上写着追杀的缘由——找到金色钥匙（小地图金点），打开出口铁门逃出去
- 掉进下陷深坑直接死亡（坑边没有斜坡，绕路走）
- 血条：玩家 20（被 Yalu 抓一次 -5）；Yalu 血量按难度 120/300/450，
  「网络炸！！」道具每发造成 150 伤害，清空后它整局消失
- /afk：使用后你 5 秒不能移动（视角可动），Yalu 被直接传送走
- 网络炸！！：Yalu 静止 3 秒 → 消失 10 秒 → 从原位置出现
- 冲刺和手电筒会发出噪音，Yalu 会循声搜查
- 被 Yalu 看见会进入追杀：心跳加速、边缘泛红、追逐音乐响起
- 被追上即 Jumpscare 死亡；拾取电池回复手电电量；地上的日记残页有前人的警告
- 迷宫带 3D 纵深：远处有 2m 下沉堑壕区，坡道可上下；失足坠落会触发镜头创伤、体力损耗与落地闷响，Yalu 同样能追进壕沟

## 更换皮肤（重要）

Yalu 的模型是标准 Minecraft 经典 64x64 皮肤 UV 布局（Steve 版型）。
把你自己的皮肤图片放到：

    assets/textures/skin.png

直接覆盖同名占位文件即可，重新打开项目自动应用到 Yalu 全身。
白色像素部位（眼睛）会自动发出红光。主菜单右侧有皮肤预览面板，
可即时确认解析效果；Steve（4px 臂）与 Alex（3px 细臂）格式自动识别。

**皮肤文件要求**：必须是真正的 MC 皮肤——64×64（或 128×128 HD）方形 PNG。
放错文件（任意尺寸的普通图片）会被自动忽略并回退到内置默认皮肤，
预览面板会显示提示；内置默认皮肤为 `assets/textures/skin_default.png`。

## 难度

主菜单可选：简单 / 普通 / 噩梦 —— 影响 Yalu 的巡逻速度、追杀速度与视野距离。

## 资产再生成

所有贴图与音效均为程序生成（零外部素材），可随时重建：

    python3 tools/gen_all.py

## 目录结构

    tools/     Python 资产生成器
